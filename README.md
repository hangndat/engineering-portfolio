## What clients can expect

- **Reliable execution:** Explicit deliverables, realistic scope, test evidence, and transparent risk reporting.
- **Architectural judgment:** Trade-offs chosen for the task rather than unnecessary frameworks or infrastructure.
- **Security by design:** Authorization boundaries, safe secrets handling, input validation, and sensible data protection.
- **Maintainable handover:** Meaningful documentation, reproducible setup, and clear operating instructions.

My preferred engagements are short, well-defined implementation projects: a useful SaaS feature, an API integration, an automation workflow, or a targeted reliability improvement.

## Evidence standard

A portfolio project is marked **Complete** only after the following evidence exists:

1. A runnable repository with a useful README and setup instructions.
2. Relevant automated tests and passing CI.
3. Security and failure-path review.
4. Architecture decisions and documented trade-offs.
5. A working demo or an accessible demonstration recording.
6. A written case study describing the problem, solution, constraints, validation, and lessons.

No fabricated metrics, performance claims, client outcomes, or deployment URLs.
