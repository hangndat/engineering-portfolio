# Proposal template — SaaS vertical slice

## Goal
Deliver a production-minded feature slice with auth boundaries, tests, and handoff docs.

## Scope
- API endpoints + validation
- UI happy path + empty/error states
- Automated tests for authorization/denial where relevant
- Setup notes and known limitations

## Out of scope
- Broad redesigns, multi-region infra, unpaid discovery beyond 1 hour

## Acceptance
- Demoable path on staging/local
- CI green for the slice
- Written handoff checklist
